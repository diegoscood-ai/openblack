Challenge natives: objects, villagers and the world

The challenge scripts' functions for objects in the world: finding, creating, moving and deleting them, their properties and script states, flocks, containers, fire, clicks and hits, special effects, mist, games and walking paths. The game has 464 of these functions in all; the language statement each comes from is shown in italics, and "called" counts are calls in the shipped challenge.chl. How the virtual machine runs them is in ../engine/script_vm.md; what each challenge is about is in ../story/.
