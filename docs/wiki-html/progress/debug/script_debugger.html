Script debugger

The debug bar's Scripts window and the editor's Log tab: a reader and debugger for the game's compiled challenge scripts, as they run in openblack's virtual machine. The scripts and their functions are in ../story/ and the virtual machine in ../engine/.

Progress: 18/21 done, 1 partial — 88%
