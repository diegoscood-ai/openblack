The Riddles

A land 2 silver scroll: once the player owns the second Indian village (Town3), a woman there offers an ancient riddle whose answer is four things to be put at once inside a ring of toadstools in the woods nearby: a wolf, something hot, a creature's dropping and a shield miracle. Solving it raises the "great power" the riddle promised: a zebra creature the player may swap to. The land as a whole is in ../land_2.md, the land's control script in ../../scripts/land2_script.md, the script program in ../../scripts/challenge_scripts.md.

Land: 2 · Giver: Annika, a woman of the Indian village Town3, at her hut · Script: LostTreasure · Reward: a zebra creature to swap to · Repeatable: no

Sources: the quest's script source (LostTreasure.txt), the shared creature-swap script it ends with (SwapCreatures.txt), the scroll-notice and reminder helpers, and its trigger in the land's control script (LandControl2.txt), all checked against the PC game's compiled challenge.chl (object types, distances, which shield is which); the game's English text table for every line and its speaker. openblack's state is judged on this tree: of the 67 script functions the quest and the scripts it starts need, 5 only log "not implemented" in src/CHLApi.cpp, and the land's control script never runs (see the first row of ../land_2.md), so the quest never appears; every row is todo unless the notes say otherwise. The internal script name ("lost treasure") is not shown to the player; the scroll is titled "The Riddles".
