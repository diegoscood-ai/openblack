Script control of computer gods

The land scripts and the challenge scripts create the computer gods and steer them: they choose which players are computer gods, give them creatures, tune their minds, move their hands, force and queue their actions, set how they feel about each other and switch them off when they are beaten. Script function names are given where needed to find them.

Progress: 8/49 done, 4 partial — 20%

All challenge script functions live in src/CHLApi.cpp; land script commands in src/LHScriptX/FeatureScriptCommands.cpp. See ../story/ for the script language and ../scripts/ for the rest of its functions.
