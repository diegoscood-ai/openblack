Vanilla bugs: story scripts

Bugs in the original game's story scripts: the gold scrolls, each land's control script, the creature's guide on Land 1 the creature curse on Land 5, and the vortices that carry the player from land to land. Silver scrolls are in silver_quests.md. Script file names are the compiled challenge scripts' own (in the game's challenge.chl); "checked in the script source" means the row was re-read in the script sources while building this list.
