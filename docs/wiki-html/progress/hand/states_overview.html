States overview

The god hand is always in exactly one state, picked afresh every frame from what the interface is doing and what the hand holds. There are eleven: hidden, normal, camera, tugging, holding, totem, scooping, creature, holding a miracle, playing a set animation, and the temple. Each state places, turns and animates the hand its own way; changing state blends the hand from where it was drawn.
