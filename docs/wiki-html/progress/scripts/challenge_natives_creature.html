Challenge natives: creatures

The challenge scripts' functions for creatures: creating and loading them, their desires, actions and learning, the leash, fighting, development and the rival gods' creatures. The game has 464 of these functions in all; the language statement each comes from is shown in italics, and "called" counts are calls in the shipped challenge.chl. How the virtual machine runs them is in ../engine/script_vm.md; what each challenge is about is in ../story/.
