Testbed scenarios

The ready-made scenarios of the testbed (about 200, in src/Debug/TestbedScenarioRegistry.cpp and the facet files src/Debug/TestbedScenario*.cpp), grouped by what they show, and the parts of the game that have none yet. A row is done when there are scenarios for that part and this tree's runner plays everything they ask for; partial when some of what they ask for logs "not in this tree yet" and is skipped. No scenario has a reference run yet. The framework is in testbed.md; how to write one is in SCENARIOS.md.

Progress: 16/36 done, 11 partial — 60%
