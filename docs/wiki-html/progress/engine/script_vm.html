Script virtual machine

The game's story, challenges and tutorial are written in Black & White's own script language, compiled into one program (challenge.chl) that a small virtual machine runs alongside the world, a step each game turn, calling into the game through several hundred native functions. Lands themselves are set up by simpler line-by-line land scripts. What the scripts do, land by land, belongs to ../story/.
