# Launch switches and stray files

The original game's command-line switches, the alternative settings file that can point it at other challenge
scripts, and the files it quietly writes about the player's creature. openblack's own switches and tools are
listed in [openblack's debug controls](../../not-in-the-original.md#openblacks-debug-controls-kept-exempt-from-removal); online services (the creature web site, the lobby)
are in [../pc_integration/](../pc_integration/) and [../multiplayer/](../multiplayer/).

## Command-line switches

Each switch starts with `-` or `/` and is matched by its start, in capitals, anywhere on the command line.

| Behaviour | Status | Where / notes |
|-----------|--------|---------------|
| `NEWGAME` skips the main menu and starts a new game at once | partial 60% | our tree's `--start-level` loads a land directly (`src/main.cpp`), but there is no main-menu flow to skip |
| `SKIRMISH` goes straight to the skirmish set-up box | pending | our tree has no such switch; `NEWGAME` overrides it, and it overrides `MULTIPLAYER`; see [../multiplayer/skirmish.md](../multiplayer/skirmish.md) |
| `PREINTROVIDEO` plays the video before the intro, which otherwise plays only while no player profile exists | done | the game's own word is read from the whole command line as the original's start-up reads it (`ScanParameters` 0x641AA0, the word at 0x641B3C: a '-' or '/' then the word in any case, whatever follows; `launch_options::HasGameSwitch`, `src/LaunchOptions.h`, from `src/main.cpp`), and left out of the named options; with it, or with our own `--pre-intro`, or while no player profile exists, the pre-intro plays (`startup::PlaysPreIntro`, `src/Gui/StartupRules.h`, from `src/GameStartup.cpp`); launched with `-PREINTROVIDEO` (2026-11-05, `refs/story/evidence/preintrovideo_switch_launch.log`) the start-up holds 100.6 s in the step after the sound banks, where the film plays (7.9 s for the whole start-up without it); tests `LaunchOptions.TheGamesOwnSwitchIsADashOrASlashThenItsWordInAnyCase`, `LaunchOptions.AGameSwitchArgumentIsLeftOutOfTheNamedOptions`, `Startup.PreIntro`; see [../video/](../video/); read 2026-11-05: what plays and when is the original's |
| `VERSION` writes `mpver.txt` beside the game holding the program's checksum (the number multiplayer uses to match versions), then carries on | done | `-VERSION` (or `/version`, in any case, anywhere on the command line) writes `mpver.txt` in the working folder as the game starts: the sum of the program file's bytes as a whole number, nothing after it (`version_file`, `src/Game/VersionFile.cpp`, from `src/main.cpp` and `Game::WriteVersionFile`); tests `VersionFile.*`; Debug > Start-up and Loading > "Write mpver.txt now (VERSION)"; the sum is of openblack's own program, as the original sums its own ([the VERSION switch](../../../engine/loop.md#the-version-switchs-file)) |
| `NOLOADMUSIC` skips loading the music | done | read from the whole command line as the game reads its switches (`launch_options::HasGameSwitch`, `src/main.cpp`); `Game::StartAudio` then registers no music bank (`audio::banks::SkipMusicBanks`, `src/Audio/Game/Banks.cpp`), as the original's audio leaves all 85 music types unregistered, so no music plays; test `AudioLaws.WithNoLoadMusicNoMusicBankIsLookedFor`, `LaunchOptions.NoLoadMusicIsOneOfTheGamesSwitches` ([the switches](../../../engine/loop.md#the-noloadmusic-and-settings-switches)) |
| `SETTINGS:<file>` reads that file (up to the next space) instead of the usual settings file | done | the name after the last `SETTINGS:`, up to a space or the line's end (`launch_options::SettingsFileNamed`); the file is read once as the game starts, from the working folder (`Game::Initialize`); without it, or with no file of that name, the game's own quest folder stays, which is all the original has without the switch (there is no other settings file); tests `LaunchOptions.TheSettingsFileIsWhatFollowsTheLastSettingsSwitchUpToASpace`, `SettingsFile.WithoutAQuestFolderLineTheGamesOwnStays` ([the switches](../../../engine/loop.md#the-noloadmusic-and-settings-switches)) |
| In that settings file, a line `QUESTDIR <folder>` makes the game load its challenge scripts from another folder, so a modded challenge file can be played without replacing the original | done | `settings_file::QuestFolder` (`src/Game/SettingsFile.cpp`): words split by spaces, commas, tabs and the line's end, a first word starting with "/" or with "/" second passed over, `QUESTDIR` in capitals with a second word taken as it is, the last one winning, a line longer than 4095 characters read in pieces; `Game::LoadStartLand` reads `<folder>Challenge.chl`, no separator added, as the original; tests `SettingsFile.*` ([the switches](../../../engine/loop.md#the-noloadmusic-and-settings-switches)) |
