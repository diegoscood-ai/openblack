Challenge natives: sound and music

The challenge scripts' functions for music, sound effects, spoken sounds and sound tags on objects. The game has 464 of these functions in all; the language statement each comes from is shown in italics, and "called" counts are calls in the shipped challenge.chl. How the virtual machine runs them is in ../engine/script_vm.md; what each challenge is about is in ../story/.
