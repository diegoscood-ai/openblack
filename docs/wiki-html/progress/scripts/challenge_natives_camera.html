Challenge natives: camera, cut scenes and fades

The challenge scripts' functions for the camera: setting and gliding it, following objects, cut-scene control, the cinema bars, fades, lens, shakes and the challenge log's pictures. The game has 464 of these functions in all; the language statement each comes from is shown in italics, and "called" counts are calls in the shipped challenge.chl. How the virtual machine runs them is in ../engine/script_vm.md; what each challenge is about is in ../story/.
