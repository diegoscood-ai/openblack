Challenge natives: advisors, text and help

The challenge scripts' functions for the good and evil advisors, the dialogue box and its spoken text, text drawn on screen, the help system, challenge markers (scrolls) and the tutorial's hand demonstrations and interface levels. The game has 464 of these functions in all; the language statement each comes from is shown in italics, and "called" counts are calls in the shipped challenge.chl. How the virtual machine runs them is in ../engine/script_vm.md; what each challenge is about is in ../story/.
