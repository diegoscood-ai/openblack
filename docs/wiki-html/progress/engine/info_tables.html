Info tables

Almost every number behind Black & White's objects, from a tree's wood to a miracle's cost or a creature's desires, comes from one file of tables, Scripts/info.dat, loaded once when the game starts. The scripts' constant names come from the same tables. A table is counted done here only when openblack reads it and its systems use it; how well each system follows it is in that system's own domain.
