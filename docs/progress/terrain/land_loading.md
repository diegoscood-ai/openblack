# Land loading and the map

Each land is a landscape file of up to 255 blocks of 16 by 16 cells laid on a 32 by 32 block map, opened by the land's
script, with a fixed-point grid of map positions that everything in the game stands on.

**Progress: 18/22 done, 0 chosen, 3 partial, 0 inferred — 91%**

How the original does it, in our wiki: [Map loading and script functions](../../../scripts/land-change-and-saving.md).

| Region questions: does an area hold coast, water, land, hill, forest, field, town or citadel, and where exactly | done | The original's region questions are the creatures' map of the land (`CreatureGlobalExplorationMap::PrecalculateMap` 0x4DF9C0): eight tests in a table (0xBDF610, 0x48 bytes each: Citadel, Town, Field, Forest, Coast, Water, Hill, Land), each with a has-it test and a where-exactly (Field's where is the coast's, `fn_00604EE0`; Land has none). Tests `CreatureExploration.RegionsTakeTheirKindsFromTheirCells`, `TheLastOfTheHighestCellsCounts`. The water, coast, stream and drinking-water searches (`src/ECS/WaterQueries.cpp`) and dry land (`pot_resource::IsDryLand`) are the other area questions.
