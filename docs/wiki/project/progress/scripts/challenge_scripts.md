# Challenge scripts

The story, the tutorial, the advisors' help and the rewards are written as scripts in the game's challenge language and shipped compiled in `Scripts/Quests/challenge.chl`. This file covers those scripts as code: how many there are, where they come from, how they start land by land, and how many of them openblack can run without reaching a function it doesn't have yet. What each challenge is about is the story domain's ([../story/](../story/)); how the virtual machine runs scripts is [../engine/script_vm.md](../engine/script_vm.md); each function the scripts call is in the `challenge_natives_*.md` files of this folder.

In all, 514 scripts: 505 call only functions openblack has, and 501 of those also start only scripts that do; the rest stop at a function that logs "not implemented" (the object delete of the two puzzle files below, and the force-feedback effect, a device row). A function counts as missing when any of its paths logs "not implemented", except a path no shipped script reaches: a creature's forced action counts as missing only for a file that forces an action row with no executor (none today: every row the shipped scripts force, 31 rows, has one), the walk path only for an animal or a creature and the cut-scene special only for special 3, which no shipped script passes ([not in the original](../../not-in-the-original.md)); counted by `tools/checks/story/challenge_script_rows.py` (2026-11-08); the object delete counts as missing only in the two files that delete a puzzle game they made (the Theseus puzzle and the Land 4 meteorites), its one path that logs it. "Runs" below means the script and every script it starts call nothing missing; whether what they do then matches the game is the natives' files' business.

The Land 1 play-through check (2026-10-22) found no function that logs "not implemented" on the path of any gold or silver scroll of Land 1; what can hold a Land 1 chapter up is elsewhere (creature actions with no executor yet, and waits for an exact arrival).

The function counts below are per source file: they count what that file's own scripts call, not the helper scripts
in other files that a challenge also runs, so a challenge may need a few more; the
per-quest files under [../story/silver_scrolls/](../story/silver_scrolls/) say what each quest needs. Every silver
scroll is listed in [../story/silver_scrolls.md](../story/silver_scrolls.md).

These challenge scripts are in the sources but not compiled into the game, so they have no row here: The Big Whale,
Landslide, The Sculptor's early silver version, Food for Thought, The Attackers, The Miracle Stones, See The Citadel,
Chimp Posse, the Creature Ladder and the swaps to horse, leopard, lion, tortoise and wolf (see the "Cut or never
started" table of [../story/silver_scrolls.md](../story/silver_scrolls.md#cut-or-never-started)).
