Map, demo and test scripts

Besides the story's lands, Scripts/ holds the map script the game reads first (map.txt), a land script for the demo's version of the third land (demo2.txt), and two developers' test lands (comp.txt for the computer players, dance.txt for dances) whose landscapes were never shipped. Land script commands are in land_script_commands.md.
