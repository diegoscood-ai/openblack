Challenge script language and functions

The story is written in the game's challenge script language and compiled into one file the game runs. Every script command and native function, one row each, is in ../scripts/ (challenge_natives_*.md); the machine that runs the scripts is in ../engine/script_vm.md. This file only says how far the story's needs are met.
